# monolythium/.github

Organization profile, security policy, and default community health files for
the canonical Monolythium GitHub organization.

Current public entry points:

- `chain-registry`: current network metadata for `testnet-69420`
- `mono-core`: core node, consensus, runtime, execution, and indexer workspace
- `mono-core-sdk`: official Rust and TypeScript SDK
- `lyth_mcp`: MCP server for live-chain reads and agent runbooks
- `.github/profile/README.md`: public organization profile
- `SECURITY.md`: organization-wide vulnerability reporting policy

Legacy v1 repositories are frozen under `mono-labs-archive`. The remaining
incubating repository in `monolythium-vision` moves here when it becomes
canonical.
