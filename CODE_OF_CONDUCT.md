# Code of Conduct

The Monolythium organization adopts the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

## Our Standards

Treat others with respect, assume good intent, disagree on substance rather than
identity, and behave professionally in issues, pull requests, discussions, and
community spaces.

Behavior that is not tolerated includes harassment, discriminatory comments,
personal attacks, sustained disruption, and publishing another person's private
information without consent.

## Enforcement

Reports of unacceptable behavior can be filed privately with the maintainers via
GitHub. Sensitive matters may be reported through GitHub Security Advisories.

Reports will be reviewed and acted on as quickly as circumstances allow.
Possible outcomes range from a private warning to a temporary or permanent ban
from project spaces, depending on severity.

The full Contributor Covenant text is authoritative; this document is a concise
project framing of it.
